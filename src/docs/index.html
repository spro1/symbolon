사용자 매뉴얼 · 1.0 베타

Symbolon 문서

Symbolon Gateway와 Symbolon ID의 제품 소개와 사용자 안내입니다.

PDF 내려받기

Symbolon Gateway는 사내 웹 서비스 앞에 두고, 로그인과 접근 권한 확인을 서비스 대신 처리하는 게이트웨이입니다. Symbolon ID는 사용자 계정, 2단계 인증, 통합 로그인(SSO)을 담당하는 로그인 서버입니다.

이 공개 문서에서는 제품 소개와, 서비스를 이용하는 직원을 위한 사용자 안내를 볼 수 있습니다. 설치, 콘솔 운영, 연동 방법을 담은 전체 매뉴얼은 도입을 검토하는 고객에게 따로 제공합니다. 요청은 GitHub 저장소(https://github.com/spro1/symbolon/issues)에 이슈로 남겨 주세요.

베타 릴리스

이 문서는 1.0.0-beta.1을 기준으로 합니다. 현재 버전은 평가와 검증을 위한 베타 릴리스입니다.
