Symbolon Docs

Product overview and user guide for Symbolon Gateway and Symbolon ID.

Download PDF

Symbolon Gateway sits in front of internal web services and handles sign-in and access checks for them. Symbolon ID is the sign-in server that manages user accounts, two-factor authentication and single sign-on (SSO).

These public docs contain the product overview and a user guide for the people who use the protected services. The full manual for installation, console operation and integration is available to customers evaluating the products. Send requests through the GitHub repository issues (https://github.com/spro1/symbolon/issues).
