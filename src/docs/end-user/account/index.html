내 계정

Symbolon ID의 내 계정 화면에서 비밀번호를 바꾸고 2단계 인증과 복구 코드를 관리하는 방법

  • 2단계 인증 관리

이 페이지에서는 내 계정 화면에서 비밀번호를 바꾸고 2단계 인증 상태를 확인하는 방법을 설명합니다.

내 계정 열기#

브라우저에서 조직의 Symbolon ID 주소 뒤에 /account를 붙여 엽니다(예: https://sso.corp.example/account). 로그인하지 않은 상태라면 로그인 화면이 먼저 나옵니다. Symbolon ID 주소로 바로 들어가 로그인해도 이 화면이 열립니다.

항목뜻
사용자 이름, 이름, 이메일내 계정 정보입니다. 바꾸려면 계정 관리자에게 요청합니다
인증 수준지금 비밀번호만으로 로그인했는지, 비밀번호 + 2단계 인증으로 로그인했는지 보여 줍니다
2단계 인증(TOTP)등록됨 또는 미등록
복구 코드남은 복구 코드 개수입니다(2단계 인증을 등록한 경우에만 보입니다)

화면 아래에는 비밀번호 변경, 2단계 인증 등록(미등록일 때), 복구 코드 재발급(등록했을 때), 로그아웃 버튼이 있습니다. Symbolon ID 관리자에게는 관리 콘솔 버튼도 보입니다.

비밀번호 변경#

  1. 비밀번호 변경을 누릅니다.
  2. 현재 비밀번호를 입력합니다.
  3. 새 비밀번호와 새 비밀번호 확인에 같은 값을 입력합니다.
  4. 변경을 누릅니다.

새 비밀번호는 다음 조건을 지켜야 합니다.

  • 12자 이상이어야 합니다. 조직 설정에 따라 다를 수 있으며, 화면에 기준이 표시됩니다.
  • 사용자 이름이 들어가면 안 됩니다.
  • 흔히 쓰이는 비밀번호는 쓸 수 없습니다.

비밀번호를 바꾸면 지금 쓰는 브라우저를 제외한 다른 기기에서는 모두 로그아웃됩니다. 휴대폰이나 다른 PC에서는 새 비밀번호로 다시 로그인합니다. 그래서 누군가 내 비밀번호를 알아낸 것 같을 때 바로 바꾸면, 그 사람의 로그인도 함께 끊깁니다.

참고

현재 비밀번호를 여러 번 틀리면 로그인 화면에서와 마찬가지로 잠시 동안 시도가 늦춰집니다. 현재 비밀번호가 기억나지 않으면 계정 관리자에게 재설정을 요청합니다.

2단계 인증 관리#

  • 미등록이라면 2단계 인증 등록을 눌러 등록합니다(2단계 인증 등록).
  • 등록됨이라면 남은 복구 코드 개수를 확인합니다. 얼마 남지 않았으면 복구 코드 재발급을 누릅니다. 새 코드 8개가 한 번만 표시되고, 이전 코드는 모두 쓸 수 없게 됩니다.
  • 복구 코드 재발급은 2단계 인증까지 마치고 로그인한 상태(인증 수준이 비밀번호 + 2단계 인증)에서만 할 수 있습니다. 비밀번호로만 로그인한 상태라면, 로그아웃한 뒤 2단계 인증이 필요한 서비스를 통해 다시 로그인하거나 계정 관리자에게 문의합니다.
  • 인증 앱을 바꾸거나 잃어버렸다면 계정 관리자에게 2단계 인증 초기화를 요청합니다. 이미 등록한 인증 앱을 사용자가 직접 지우는 기능은 없습니다.
