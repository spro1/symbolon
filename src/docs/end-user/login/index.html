로그인

업무 서비스에 접속하면 나오는 Symbolon ID 로그인 화면을 쓰는 방법과 로그인이 안 될 때 확인할 것

업무 서비스에 접속하면 로그인 화면이 먼저 나옵니다. 이 페이지에서는 로그인하는 방법과 로그인이 안 될 때 확인할 것을 설명합니다.

로그인하기#

  1. 평소처럼 서비스 주소(예: https://wiki.corp.example)로 접속합니다.
  2. 아직 로그인하지 않았다면 Symbolon ID 로그인 화면으로 자동으로 넘어갑니다.
  3. 주소 표시줄의 도메인이 조직의 로그인 주소가 맞는지 확인합니다.
  4. 사용자 이름과 비밀번호를 입력하고 로그인을 누릅니다.
  5. 서비스가 추가 인증을 요구하면 인증 앱에 표시된 6자리 코드를 입력합니다(2단계 인증).
  6. 로그인이 끝나면 처음 접속하려던 화면으로 돌아갑니다.

주의

비밀번호를 입력하기 전에 주소 표시줄의 도메인을 꼭 확인합니다. 로그인 화면 아래에도 같은 안내가 있습니다. 메일이나 메신저로 받은 링크가 비슷하게 생긴 다른 주소로 연결되는 피싱일 수 있기 때문입니다. 조직의 로그인 주소가 무엇인지는 계정 관리자에게 확인합니다.

화면 오른쪽 위에서 라이트 · 시스템 설정 · 다크 중 하나를 골라 화면 밝기를 바꿀 수 있습니다.

한 번 로그인으로 여러 서비스 이용#

한 번 로그인하면 일정 시간 동안은 같은 계정으로 연결된 다른 서비스에 들어갈 때 로그인 화면이 다시 나오지 않습니다. 이때 화면이 잠깐 깜박이며 넘어갈 수 있는데, 정상적인 동작입니다.

상황동작
서비스를 계속 쓰고 있을 때로그인이 그대로 유지됩니다. 다만 서비스마다 정해진 시간이 지나면 화면에 아무것도 띄우지 않고 로그인 상태를 다시 확인합니다
8시간 넘게 아무 서비스도 쓰지 않았을 때다시 로그인해야 합니다
로그인한 지 24시간이 지났을 때다시 로그인해야 합니다

정확한 시간은 조직 설정에 따라 다를 수 있습니다.

로그인이 안 될 때#

화면 문구뜻과 할 일
사용자 이름 또는 비밀번호가 올바르지 않습니다.사용자 이름과 비밀번호를 다시 확인합니다. Caps Lock이 켜져 있지 않은지, 한/영 전환이 맞는지도 살펴봅니다
여러 번 틀리면 같은 접속 위치에서의 로그인이 잠시 지연됩니다. 올바른 비밀번호도 거절되면 조금 뒤에 다시 시도하세요.여러 번 틀려서 로그인이 잠시 늦춰지고 있을 수 있습니다. 몇 분 기다렸다가 다시 시도합니다. 그래도 안 되면 계정 관리자에게 잠금 해제를 요청합니다
로그인 시도 횟수가 너무 많습니다. 잠시 후 다시 시도하세요.같은 위치에서 로그인 실패가 많았습니다. 몇 분 기다린 뒤 다시 시도합니다
지금은 요청이 많아 처리할 수 없습니다. 잠시 후 다시 시도하세요.로그인하려는 사람이 한꺼번에 몰리고 있습니다. 몇 초 뒤 다시 시도합니다
요청을 확인할 수 없습니다. 페이지를 새로 고친 뒤 다시 시도하세요.로그인 화면을 오래 열어 두었거나 다른 탭에서 로그인 상태가 바뀌었습니다. 페이지를 새로 고친 뒤 다시 로그인합니다

참고

보안을 위해 로그인 화면은 비밀번호가 틀렸는지, 계정이 없는지, 계정이 정지되었는지를 구분해서 알려 주지 않습니다. 비밀번호가 맞는데도 계속 거절된다면 계정 관리자에게 문의합니다.

로그인은 되었는데 서비스 화면 대신 "접근 권한이 없습니다"나 "로그인 서비스에 연결할 수 없습니다"라는 화면이 나오면 접근 거부·일시 장애 화면을 참고합니다.

비밀번호를 잊었을 때#

Symbolon ID에는 비밀번호를 스스로 찾는 기능이 없습니다. 계정 관리자에게 비밀번호 재설정을 요청합니다. 비밀번호가 재설정되면 모든 기기에서 로그아웃되므로 새 비밀번호로 다시 로그인합니다. 로그인한 뒤에는 내 계정에서 원하는 비밀번호로 바꿀 수 있습니다.
