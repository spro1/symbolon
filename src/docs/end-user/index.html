최종 사용자 가이드

Symbolon Gateway와 Symbolon ID로 보호되는 업무 서비스를 쓰는 분을 위한 로그인, 2단계 인증, 내 계정, 로그아웃 안내

이 장은 업무 서비스를 쓰는 분들을 위한 안내입니다. 업무 시스템에 접속하면 나오는 로그인 화면부터 인증 앱 등록, 비밀번호 변경, 오류 화면, 로그아웃까지 쉬운 말로 설명합니다.

조직 계정 하나로 로그인해 두면, 같은 방식으로 연결된 다른 서비스에는 다시 로그인하지 않고 들어갈 수 있습니다. 계정을 만들거나 잃어버린 인증 앱을 초기화하는 일은 조직의 계정 관리자가 맡습니다.

  • 로그인업무 서비스에 접속하면 나오는 Symbolon ID 로그인 화면을 쓰는 방법과 로그인이 안 될 때 확인할 것
  • 2단계 인증 등록인증 앱을 Symbolon ID에 등록하는 방법, 로그인할 때 인증 코드를 입력하는 방법, 복구 코드를 보관하는 방법
  • 내 계정Symbolon ID의 내 계정 화면에서 비밀번호를 바꾸고 2단계 인증과 복구 코드를 관리하는 방법
  • 접근 거부·일시 장애 화면서비스 대신 나타나는 접근 거부(403) 화면과 로그인 서비스 연결 불가(503) 화면의 뜻, 그리고 그때 할 일
  • 로그아웃서비스와 Symbolon ID에서 로그아웃하는 방법, 로그아웃 확인 화면, 한 곳의 로그아웃이 다른 서비스에도 적용되는 방식
