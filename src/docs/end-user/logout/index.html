로그아웃

서비스와 Symbolon ID에서 로그아웃하는 방법, 로그아웃 확인 화면, 한 곳의 로그아웃이 다른 서비스에도 적용되는 방식

이 페이지에서는 로그아웃하는 방법과, 한 곳에서 로그아웃하면 다른 서비스에서도 함께 로그아웃되는 방식을 설명합니다.

로그아웃하기#

다음 두 가지 방법 중 하나로 로그아웃합니다.

  • 서비스 화면의 로그아웃 메뉴를 누릅니다(서비스에 로그아웃 메뉴가 있는 경우).
  • 내 계정 화면에서 로그아웃을 누릅니다.

로그아웃을 누르면 Symbolon ID 화면이 정말 로그아웃할지 확인합니다.

  1. 안내 문구에 표시된 계정이 내 계정인지 확인합니다.
  2. 로그아웃을 누릅니다.

서비스에 따라서는 이 확인 화면 없이 바로 로그아웃되기도 합니다. 로그아웃이 끝나면 서비스의 첫 화면으로 돌아가는데, 이제 로그인 상태가 아니므로 로그인 화면이 다시 나옵니다. 돌아갈 곳이 지정되어 있지 않으면 "로그아웃되었습니다" 안내 화면에서 끝납니다.

다른 서비스에서도 로그아웃됩니다#

Symbolon ID에서 로그아웃하면, 그 로그인으로 들어갔던 다른 서비스에서도 함께 로그아웃됩니다. 보통 몇 초 안에 반영되므로, 열어 둔 다른 서비스 탭에서 다음 화면으로 넘어가면 다시 로그인하라는 화면이 나옵니다.

공용 PC나 다른 사람과 함께 쓰는 기기에서는 일을 마친 뒤 반드시 로그아웃하고 브라우저를 닫습니다.

참고

브라우저를 닫기만 해서는 Symbolon ID 로그인이 끝나지 않을 수 있습니다. 공용 기기에서는 꼭 로그아웃 버튼을 누릅니다.

"로그아웃하시겠습니까?" 확인 페이지#

메일이나 다른 사이트의 링크를 눌러 서비스의 로그아웃 주소로 들어오면, 바로 로그아웃되지 않고 이 확인 페이지가 나옵니다. 다른 사이트가 나도 모르게 나를 로그아웃시키지 못하도록 막기 위한 것입니다.

  • 정말 로그아웃하려면 로그아웃을 누릅니다.
  • 로그아웃할 생각이 없었다면 창을 그냥 닫거나 서비스 주소로 이동합니다. 로그인 상태는 그대로 유지됩니다.

서비스 화면 안의 로그아웃 메뉴를 눌렀거나 로그아웃 주소를 주소 표시줄에 직접 입력했다면, 이 페이지 없이 바로 로그아웃됩니다.

관리자가 로그아웃시킨 경우#

계정 관리자가 내 로그인을 끊거나 비밀번호·2단계 인증을 재설정하면 모든 서비스에서 로그아웃됩니다. 내가 직접 비밀번호를 바꾸거나 2단계 인증을 등록한 경우에도, 지금 쓰는 브라우저를 제외한 다른 기기에서는 로그아웃됩니다. 이때 "이 계정의 세션이 관리자에 의해 종료되었습니다"라는 화면이 나오면 잠시 뒤 다시 로그인합니다(접근 거부·일시 장애 화면).

관리자를 위한 자세한 동작 설명은 세션과 Back-Channel Logout과 즉시 폐기에 있습니다.
