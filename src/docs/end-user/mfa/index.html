2단계 인증 등록

인증 앱을 Symbolon ID에 등록하는 방법, 로그인할 때 인증 코드를 입력하는 방법, 복구 코드를 보관하는 방법

이 페이지에서는 휴대폰 인증 앱을 등록하고 복구 코드를 보관하는 방법을 설명합니다. 2단계 인증을 쓰면 비밀번호가 다른 사람에게 알려지더라도 그 사람이 내 계정으로 로그인하기 어렵습니다.

준비물#

  • 휴대폰에 설치한 인증 앱. Google Authenticator, Microsoft Authenticator처럼 6자리 시간 기반 코드(TOTP)를 만드는 앱이면 어느 것이든 됩니다.
  • 현재 비밀번호

등록하기#

등록 화면은 두 가지 경우에 나옵니다. 2단계 인증이 필요한 서비스에 처음 들어갈 때 자동으로 나오고, 내 계정에서 2단계 인증 등록을 눌러 직접 열 수도 있습니다.

  1. 인증 앱을 열고 계정 추가(＋)를 누른 다음 "설정 키 입력"(앱에 따라 "키 직접 입력")을 고릅니다.
  2. 화면에 보이는 설정 키를 앱에 입력합니다. 계정 이름은 알아보기 쉽게(예: "Symbolon ID") 적고, 방식은 "시간 기반"을 고릅니다.
    • 휴대폰으로 이 화면을 보고 있다면 otpauth 주소로 등록을 펼쳐 주소를 눌러도 됩니다.
  3. 등록 화면의 현재 비밀번호 칸에 비밀번호를 입력합니다.
  4. 인증 앱에 나타난 6자리 숫자를 인증 코드 칸에 입력하고 등록 후 계속을 누릅니다.
  5. 복구 코드 8개가 나옵니다. 다음 절의 안내대로 보관한 뒤 보관 확인 후 계속을 누릅니다.

등록을 마치면 지금 쓰는 브라우저를 제외한 다른 기기에서는 모두 로그아웃됩니다. 다른 기기에서는 다시 로그인합니다.

참고

Symbolon ID 등록 화면에는 QR 코드가 없으므로 설정 키를 직접 입력합니다. 설정 키는 등록 화면을 열 때마다 새로 만들어집니다. 등록을 마치기 전에 화면을 다시 열었다면 "설정 키가 새로 발급되었습니다"라는 안내가 나오니, 새 키로 앱에 다시 등록합니다.

경고

설정 키만 있으면 누구든 내 인증 코드를 만들 수 있습니다. 화면을 캡처하거나 메모·메신저에 남기지 말고, 다른 사람에게 보여 주지도 않습니다. 실수로 남겼다면 계정 관리자에게 알려 다시 등록합니다.

도움말

관리 콘솔을 쓰는 관리자 계정은 처음 등록할 때 등록 코드도 입력해야 합니다. 등록 코드는 계정을 만든 사람에게서 비밀번호와 다른 경로로 받는 일회용 코드입니다(관리자의 첫 등록).

복구 코드 보관#

복구 코드는 휴대폰을 잃어버렸거나 인증 앱을 쓸 수 없을 때 인증 코드 대신 입력하는 일회용 코드입니다. abcde-fghij 모양이며 모두 8개가 발급됩니다.

  • 복구 코드는 지금 한 번만 보이고, 나중에 다시 볼 수 없습니다.
  • 휴대폰이 아닌 곳에 보관합니다. 비밀번호 관리자에 넣어 두거나, 종이에 적어 잠금 서랍에 보관하는 식입니다.
  • 코드 하나는 한 번만 쓸 수 있습니다. 남은 개수는 내 계정에서 확인할 수 있습니다.
  • 코드를 거의 다 썼거나 다른 사람이 봤을 수 있다면 내 계정에서 복구 코드 재발급을 누릅니다. 재발급하면 이전 코드는 모두 쓸 수 없게 됩니다.

로그인할 때 인증 코드 입력하기#

2단계 인증이 필요한 서비스에 들어가면 비밀번호를 입력한 다음 이 화면이 나옵니다. 이미 비밀번호로 로그인한 상태에서 2단계 인증이 필요한 화면으로 옮겨 가면, 비밀번호는 다시 묻지 않고 이 화면만 나옵니다.

  1. 인증 앱을 열어 Symbolon ID 항목에 표시된 6자리 숫자를 확인합니다.
  2. 인증 코드 칸에 입력하고 확인을 누릅니다. 숫자는 30초마다 바뀌므로, 곧 바뀔 것 같으면 다음 숫자가 나올 때까지 기다렸다가 입력합니다.
  3. 인증 앱을 쓸 수 없다면 같은 칸에 복구 코드를 입력합니다.

"인증 코드가 올바르지 않습니다"가 계속 나오면 휴대폰의 시각이 자동 설정으로 되어 있는지 확인합니다. 여러 번 틀리면 한동안 코드를 입력할 수 없습니다.

휴대폰을 바꾸거나 잃어버렸을 때#

상황할 일
새 휴대폰으로 바꿨고, 예전 휴대폰이 아직 있음인증 앱의 계정 옮기기 기능을 씁니다. 또는 복구 코드로 로그인한 뒤 계정 관리자에게 초기화를 요청하고, 새 휴대폰으로 다시 등록합니다
휴대폰을 잃어버렸고, 복구 코드는 있음복구 코드로 로그인합니다. 그다음 계정 관리자에게 알려 2단계 인증을 초기화하고 새로 등록합니다
휴대폰도 복구 코드도 없음계정 관리자에게 2단계 인증 초기화를 요청합니다. 본인 확인을 거쳐 초기화되면 모든 기기에서 로그아웃되고, 다음에 로그인할 때 다시 등록합니다
