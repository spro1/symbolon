접근 거부·일시 장애 화면

서비스 대신 나타나는 접근 거부(403) 화면과 로그인 서비스 연결 불가(503) 화면의 뜻, 그리고 그때 할 일

이 페이지의 내용
  • 요청 ID
  • 접근 권한이 없습니다 (403)
  • 로그인 서비스에 연결할 수 없습니다 (503)
  • 일시적으로 사용할 수 없습니다 (503)
  • 관리자에게

서비스에 접속했는데 원래 화면 대신 짧은 안내 화면이 나올 때가 있습니다. 이 화면은 서비스에 들어가기 전에 접근을 확인하는 게이트웨이가 보여 주는 것입니다. 이 페이지에서는 화면별 뜻과 그때 무엇을 하면 되는지 설명합니다.

요청 ID#

모든 안내 화면 아래에는 요청 ID가 있습니다. 영문과 숫자가 하이픈으로 이어진 긴 값입니다. 관리자는 이 값으로 그때 무슨 일이 있었는지 기록을 찾습니다. 문의할 때는 화면 캡처나 요청 ID를 함께 보내고, 접속한 시각과 주소도 적어 줍니다.

접근 권한이 없습니다 (403)#

뜻: 로그인은 되었지만, 이 서비스(또는 이 메뉴)를 쓸 수 있는 사용자 목록에 내가 들어 있지 않습니다. 보안을 위해 어떤 그룹에 속해야 하는지는 화면에 나오지 않습니다.

할 일:

  1. 다른 계정으로 로그인해야 하는 서비스인지 확인합니다. 그렇다면 로그아웃한 뒤 맞는 계정으로 다시 로그인합니다.
  2. 권한이 필요하면 요청 ID를 함께 적어 서비스 관리자에게 문의합니다. 화면에 나오는 문의 안내 문구는 조직마다 다를 수 있습니다.
  3. 권한을 받은 뒤에도 이 화면이 계속 나오면 로그아웃했다가 다시 로그인합니다. 권한 변경은 로그인 상태를 다시 확인할 때(보통 1시간 안) 반영됩니다.

비슷한 화면이 몇 가지 더 있습니다.

화면 제목과 문구뜻과 할 일
추가 인증이 필요합니다 — 이 경로는 2단계 인증을 마친 뒤에 접근할 수 있습니다.이 메뉴는 인증 앱 코드까지 입력해야 쓸 수 있습니다. 2단계 인증 화면에서 코드를 입력했는지 확인하고, 아직 등록하지 않았다면 등록합니다
접근할 수 없습니다 — 이 계정의 세션이 관리자에 의해 종료되었습니다. 잠시 후 다시 시도하세요.관리자가 내 로그인을 끊었습니다. 잠시 뒤 다시 로그인합니다. 계속 막히면 계정 관리자에게 문의합니다
접근할 수 없습니다 — 이 주소는 게이트웨이에 등록되어 있지 않습니다.주소가 틀렸거나 아직 열리지 않은 서비스입니다. 주소를 다시 확인합니다
로그인을 완료할 수 없습니다 — 로그인 요청을 확인할 수 없습니다. 원래 주소로 다시 접속해 주세요.로그인하는 도중 시간이 너무 오래 지났거나, 여러 탭에서 동시에 로그인했습니다. 서비스 주소로 다시 접속합니다

로그인 서비스에 연결할 수 없습니다 (503)#

뜻: 로그인을 처리하는 서버(Symbolon ID)가 잠시 응답하지 않습니다. 게이트웨이는 누구인지 확인할 수 없는 사용자를 들여보내지 않기 때문에, 요청을 통과시키는 대신 이 안내를 보여 줍니다. 내 계정이나 권한에 문제가 있는 것은 아닙니다.

할 일:

  1. 30초~1분쯤 기다린 뒤 페이지를 새로 고칩니다.
  2. 몇 분이 지나도 그대로라면 요청 ID를 함께 적어 서비스 관리자나 헬프데스크에 알립니다.

일시적으로 사용할 수 없습니다 (503)#

이 화면에는 "게이트웨이가 아직 접근 정책을 받지 못했습니다", "최신 접근 정책을 확인하지 못하고 있습니다" 같은 문구가 함께 나옵니다. 게이트웨이가 다시 시작하는 중이거나, 게이트웨이와 관리 서버 사이의 연결에 문제가 생겼다는 뜻입니다. 잠시 뒤 다시 시도하고, 계속 같은 화면이 나오면 요청 ID를 함께 적어 서비스 관리자에게 알립니다.

관리자에게#

  • 관리자는 안내 화면의 요청 ID로 Symbolon Gateway 콘솔의 접근 이벤트에서 그 요청의 기록을 찾을 수 있습니다(접근 이벤트). 허용된 요청이라면 같은 요청 ID가 서비스에도 전달되므로 서비스 로그와 맞춰 볼 수 있습니다. 거부된 요청은 서비스까지 가지 않으므로 서비스 로그에는 남지 않습니다(Backend가 받는 헤더).
  • 403 화면에 나오는 문의 안내 문구는 관리자가 바꿀 수 있습니다.
  • 로그인하지 않은 요청이 브라우저의 화면 이동이 아니라 화면 안에서 데이터를 불러오는 요청이라면, 로그인 화면으로 보내지 않고 로그인이 필요하다는 응답(401)과 로그인을 시작할 주소를 돌려줍니다(Bearer 토큰 API).
