Symbolon Gateway는 사내 웹 서비스 앞단에서 HTTPS 연결과 로그인, 그룹별 접근 권한 확인을 대신 처리합니다. 회사 계정과 그룹은 Symbolon ID에서 관리하면 되고, 이미 쓰고 있는 로그인 서버가 있다면 그 서버에 연결해도 됩니다.

사내 도메인과 HTTPS

서비스마다 사내 도메인을 연결하고 HTTPS로 접속하게 합니다. 인증서는 자동으로 발급되고 만료되기 전에 알아서 갱신됩니다.

그룹별 접근 권한

서비스마다 접속을 허용할 그룹을 정합니다. 허용된 그룹에 속한 사람만 서비스를 쓸 수 있습니다.

서비스 코드는 그대로

로그인과 권한 확인은 게이트웨이가 처리합니다. 기존 서비스에 로그인 기능을 새로 만들 필요가 없습니다.

동작 방식

사용자가 서비스에
접속하는 과정

사용자는 평소처럼 사내 주소로 접속하기만 하면 됩니다. 별도로 설치할 프로그램은 없습니다.

  1. 1

    회사 계정으로 한 번 로그인합니다

    처음 접속하면 로그인 화면이 나옵니다. 한 번 로그인하면 다른 사내 서비스도 다시 로그인하지 않고 쓸 수 있습니다.

  2. 2

    게이트웨이가 권한을 확인합니다

    게이트웨이는 요청마다 로그인한 사람이 누구인지, 이 서비스에 접속해도 되는지 확인합니다.

  3. 3

    권한이 확인된 사람만 서비스를 씁니다

    권한이 있는 사람의 요청만 서비스로 전달됩니다. 권한이 없으면 안내 페이지가 표시됩니다.

Symbolon Gateway

심볼론 게이트웨이 · 사내 서비스용 게이트웨이

사내 웹 서비스에 사내 도메인과 HTTPS를 적용하고, 요청마다 로그인 여부와 접근 권한을 확인한 뒤 서비스로 전달합니다.

  • 서비스를 등록하고 사내 도메인을 연결하면 인증서는 자동으로 발급·갱신됩니다.
  • 서비스와 경로마다 로그인 여부, 허용 그룹, 2단계 인증 요구를 정합니다.
  • 변경 승인과 되돌리기, 실시간 모니터링, 감사 기록을 지원합니다.
단독으로 쓸 때 이미 쓰고 있는 표준 OIDC 로그인 서버에 연결합니다자세히 보기

Symbolon ID

심볼론 ID · 로그인(SSO) 서버

회사의 사용자와 그룹을 한곳에서 관리합니다. 사용자는 한 번 로그인하면 여러 사내 서비스를 쓸 수 있습니다.

  • 사용자와 그룹을 관리하고, 비밀번호에 인증 앱을 더한 2단계 인증을 지원합니다.
  • 로그인 화면과 사용자가 직접 쓰는 내 계정 화면을 제공합니다.
  • 표준 OIDC를 지원하므로 다른 사내 제품도 바로 연결할 수 있습니다.
