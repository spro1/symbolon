Both products are installed on servers you run. They fit virtual machines, containers and Kubernetes, and work on internal networks without internet access. For each option, we state plainly how far it was tested in 1.0 beta.

Install options and test status

The evaluation install is
tested end to end

In 1.0 beta, the only setup tested end to end is the evaluation install on a single machine. The other options come with the files and documentation you need, but have not been tested on real servers yet.

What each install option includes and its test status

Start with the evaluation install

We suggest installing the evaluation on one machine, checking the features, then applying it to one less sensitive service first.

A gateway group per environment

If you have several environments, such as a data center and a cloud, give each one a gateway group and point service domains at the right group.

Recommended sizing

Size the gateway by
concurrent users

Four tiers based on the number of users at the busiest time. Minimum is enough to handle that load. Recommended leaves headroom so service continues if one server stops.

Gateway sizing is shown as “number of servers × size of each server”. At L and XL, memory runs short before CPU, so we recommend generous memory.

What you need

What to prepare
before installing

You prepare the items below in your environment. Detailed requirements come with the installation documents.

Servers and a database

Servers for the gateway, the management server and Symbolon ID, plus a database server for them to use.

Internal DNS

You create the DNS records that point service domains at the gateway.

Certificate trust

Install the product's CA certificate on user PCs so browsers trust the certificates it issues.

Network setup

Set up the network so internal services accept only requests that come through the gateway.

Not sure what fits
your environment?

Tell us your number of users and services and your environment, and we'll work out a suitable setup with you. Open a GitHub issue to get started.
