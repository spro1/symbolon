One company account
for every internal service

Symbolon ID is a sign-in server that manages your company's users and groups in one place. Users sign in once to use many services, and administrators manage accounts and access in one place. It also works without Symbolon Gateway.

Users

Users manage
their own accounts

Users change passwords, set up two-step verification and get new recovery codes on their own “My account” page, which means fewer requests for administrators.

  • Two-step verification with an authenticator app on a phone.
  • One-time recovery codes in case the authenticator app is lost.
  • Passwords that are too short or too common are rejected.
  • Repeated failed sign-ins are limited automatically.

Administrators

Manage users and groups
in one place

Add users and create groups in the admin console. The same groups are used in Symbolon Gateway access policies and in the permission settings of other internal products.

Two-step verification for admins

Only administrators with two-step verification set up can use the admin console. Granting or removing admin rights is recorded separately.

Connect other systems

Let systems such as HR tools look up users and groups, with an allowed scope set for each connected system.

Audit log

Sign-ins and administrative actions are recorded for later review.

Standards

Standard OIDC, so other
products can connect too

Internal products that don't go through Symbolon Gateway can connect to Symbolon ID directly if they support OIDC, so users sign in with the same account.

Web apps and servers

Supports web services that users sign in to, as well as server-to-server calls with no user involved.

{{include name="i-lock"}}

Tokens per service

Each token is issued for a specific service. A token issued for one service can't be used with another.

{{include name="i-logout"}}

Sign-out propagation

When a user signs out or an account is disabled, connected services are told so the user is signed out there too.

Not yet supported in the beta

LDAP and Active Directory integration, SAML and security key (WebAuthn) sign-in are not supported yet. They are under consideration after the beta.
