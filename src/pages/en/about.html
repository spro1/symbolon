About

Symbolon is built by independent developer spro1, who does the design, implementation and testing alone. Symbolon is the ancient Greek word for a token used to confirm identity.

How it's built

The principles behind it

Only what's been checked

Feature descriptions are based on what automated tests have confirmed. Setups that weren't tested and performance that wasn't measured are labeled as such.

Few external dependencies

External libraries are used only where needed. A single library with a known vulnerability blocks the release.

Works on closed networks

No external fonts or outside servers are needed, so the admin console works on internal networks without internet access.
