고객의 서버에
직접 설치해서 씁니다

두 제품은 고객이 운영하는 서버에 설치합니다. 가상 머신, 컨테이너, Kubernetes 환경에 맞춰 배치할 수 있고, 인터넷이 연결되지 않은 사내망에서도 동작합니다. 설치 방식마다 1.0 베타에서 어디까지 검증했는지 있는 그대로 적었습니다.

설치 방식권장 사양준비할 것

설치 방식과 검증 상태

처음부터 끝까지 검증한
구성은 평가판입니다

1.0 베타에서 처음부터 끝까지 검증한 구성은 장비 한 대에 설치하는 평가판뿐입니다. 나머지 방식은 필요한 파일과 문서를 제공하지만, 실제 서버에서의 검증은 아직 진행하지 않았습니다.

설치 방식별 제공 내용과 검증 상태
설치 방식상태제공하는 것
평가판검증 완료장비 한 대에 두 제품과 견본 서비스를 함께 설치하는 스크립트를 제공합니다. 기능을 직접 써 보는 용도이며 운영용은 아닙니다.
가상 머신 · 물리 서버검증 전게이트웨이를 서버의 서비스로 등록하는 systemd 서비스 파일을 제공합니다. 실제 서버에서의 검증은 아직 진행하지 않았습니다.
컨테이너검증 전컨테이너 이미지를 만드는 데 필요한 파일을 제공합니다. 이미지를 빌드해 실행하는 검증은 아직 진행하지 않았습니다.
Kubernetes구성 안내권장 배치를 문서로 안내합니다. 배포용 매니페스트와 Helm 차트는 아직 제공하지 않습니다.

Linux 서버와 여러 대로 구성한 환경에서는 아직 시험하지 않았습니다. 관리 서버 이중화와 설치 패키지는 베타 이후에 검토합니다.

평가판으로 시작

장비 한 대에 평가판을 설치해 기능을 확인한 뒤, 덜 민감한 서비스 하나에 먼저 적용해 보는 순서를 권합니다.

환경마다 게이트웨이 그룹

데이터센터와 클라우드처럼 환경이 여러 곳이면 환경마다 게이트웨이 그룹을 두고, 서비스 도메인을 해당 그룹으로 연결합니다.

설치 지원

운영 환경의 배치 방법은 도입을 검토하는 고객에게 설치 문서와 함께 따로 안내해 드립니다.

규모별 권장 사양

동시 사용자 수에 맞춰
게이트웨이 사양을 고릅니다

가장 붐빌 때 동시에 접속하는 사용자 수를 기준으로 네 단계로 나눴습니다. 최소 사양은 그 부하를 처리할 수 있는 구성이고, 권장 사양은 서버 한 대가 멈춰도 서비스가 이어지도록 여유를 둔 구성입니다.

산정치1.0 베타 기준 산정치 — macOS 단일 장비 실측을 바탕으로 실측의 50%로 보수적으로 잡은 값. Linux 서버 실측과 고객 PoC에서 확정합니다.

Symbolon ID, 관리 서버, 데이터베이스의 사양은 도입을 검토하는 고객에게 요청 시 제공합니다.
