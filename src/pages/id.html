회사 계정 하나로
여러 사내 서비스에 로그인합니다

Symbolon ID는 회사의 사용자와 그룹을 관리하는 로그인 서버입니다. 사용자는 한 번 로그인하면 여러 서비스를 쓸 수 있고, 관리자는 계정과 권한을 한곳에서 관리합니다. Symbolon Gateway 없이 단독으로도 쓸 수 있습니다.

문의하기 제품소개서 받기

사용자

계정 관리는
사용자가 직접 합니다

비밀번호 변경, 2단계 인증 등록, 복구 코드 재발급을 사용자가 “내 계정” 화면에서 직접 처리합니다. 그만큼 관리자에게 들어오는 요청이 줄어듭니다.

  • 스마트폰 인증 앱으로 2단계 인증을 쓸 수 있습니다.
  • 인증 앱을 잃어버렸을 때를 대비해 일회용 복구 코드를 발급합니다.
  • 너무 짧거나 흔한 비밀번호는 쓸 수 없습니다.
  • 로그인 실패가 반복되면 자동으로 제한합니다.

관리자

사용자와 그룹을
한곳에서 관리합니다

관리 콘솔에서 사용자를 등록하고 그룹을 만듭니다. 여기서 만든 그룹은 Symbolon Gateway의 접근 정책이나 다른 사내 제품의 권한 설정에서 그대로 쓰입니다.

관리자는 2단계 인증 필수

관리 콘솔은 2단계 인증을 등록한 관리자만 쓸 수 있습니다. 관리자 권한을 주거나 뺀 기록은 따로 남습니다.

다른 시스템과 연동

인사 시스템처럼 사용자와 그룹 정보가 필요한 시스템을 연결할 수 있습니다. 시스템마다 조회할 수 있는 범위를 따로 정합니다.

감사 기록

로그인과 관리 작업은 감사 기록으로 남아 나중에 확인할 수 있습니다.

표준 지원

표준 OIDC를 지원해
다른 제품도 연결할 수 있습니다

Symbolon Gateway를 거치지 않는 사내 제품도 OIDC를 지원한다면 Symbolon ID에 직접 연결해 같은 계정으로 로그인하게 할 수 있습니다.

서비스별 토큰

토큰은 받을 서비스를 지정해서 발급합니다. 한 서비스용으로 받은 토큰은 다른 서비스에서 쓸 수 없습니다.

{{include name="i-logout"}}

로그아웃 전파

로그아웃하거나 계정을 비활성화하면 연결된 서비스에도 알려서 함께 로그아웃되게 합니다.

베타에서 아직 지원하지 않는 것

LDAP와 Active Directory 연동, SAML, 보안 키(WebAuthn) 로그인은 아직 지원하지 않습니다. 베타 이후에 검토합니다.

공통 로그인이
아직 없다면

Symbolon ID로 회사 로그인을 먼저 갖추고, 사내 서비스에는 Symbolon Gateway를 적용하는 방식으로 시작할 수 있습니다.
